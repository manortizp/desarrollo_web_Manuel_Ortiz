# desarrollo_web_Manuel_Ortiz

La aplicación esta dividida en 4 .html, y 2 .js, en particular, scripts.js está asociado a index.html
y formulario.js está asociado a agregar-actividad.html

actividades-recreativas/
│
├── index.html               # Portada y navegación principal.
├── agregar-actividad.html   # Formulario para informar nueva actividad.
├── listado.html             # Listado de actividades y vista de detalle.
├── estadisticas.html        # Página con gráficos y estadísticas.
├── css/
│   └── estilos.css          # Hojas de estilo personalizadas.
├── js/
│   ├── formulario.js        # Validaciones y lógica del formulario.
│   ├── listado.js           # Funciones para el listado y detalle de actividades.
│   └── graficos.js          # Configuración de gráficos (Chart.js).
└── README.md                # Este archivo.
